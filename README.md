# claude-code-plugin-enhancement

Claude Code 插件集 (本地 marketplace)。

## 安装

```
/plugin marketplace add ChenYCL/claude-code-plugin-enhancement
/plugin install todo-queue@claude-code-plugin-enhancement
```

## 插件列表

| 插件 | 说明 |
|---|---|
| [todo-queue](plugins/todo-queue/README.md) | 持久化 todo 队列: 自动归集会话/代码中的 TODO, 约束当前目标任务不跑偏, 支持队列自动推进 |
